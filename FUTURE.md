The 3 Long-Term Scaling Milestones ("Plan B")
These are not bugs, but future architectural milestones when you outgrow a single server or small teams:

LiveKit SFU: Replaces P2P mesh when video calls exceed 4 people.
Redis Pub/Sub: Connects multiple Node.js server instances if horizontally scaling.
CRDTs (Yjs): Enables character-by-character simultaneous Google-Docs-style text editing on the exact same card.
